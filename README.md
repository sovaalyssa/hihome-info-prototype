# Hi home.info — clickable prototype

GitHub Pages-ready static prototype.

Pages:
- index.html — main page
- about.html — about the Hi home.info portal
- magazine.html — Hi home magazine
- events.html — Hi home events
- franchise.html — Hi home franchise
- designers.html — designers search
- suppliers.html — suppliers search
- apartments.html — apartments
- houses.html — houses
- public-interiors.html — public interiors
- 3d-visualizations.html — 3D visualizations

All pages are static HTML and use relative links. Keep all HTML files in the repository root.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Upload every file from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait a few minutes and open the URL shown by GitHub Pages.
